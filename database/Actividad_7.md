# Actividad 7: Actualizar horarios y médicos en la página web

## Descripción

Se realizó una simulación de actualización de información para verificar que los cambios realizados en la base de datos puedan reflejarse en la página web del Consultorio Santa María Josefa. Durante esta actividad se modificaron horarios de atención y especialidades médicas con el objetivo de mantener la información disponible para los pacientes de forma actualizada.

## Cambios realizados

| INFORMACIÓN ACTUALIZADA | Cambio Realizado |
| :--- | :--- |
| Pediatra | Martes y Jueves 10:00 a 13:00 |
| Ginecología | Lunes y Viernes 12:00 a 15:00 |

## Resultado obtenido

Se comprobó que la información puede mantenerse actualizada, permitiendo que los pacientes accedan a horarios y servicios vigentes mediante la página web[cite: 12].
