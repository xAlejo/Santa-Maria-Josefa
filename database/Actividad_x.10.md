# Actividad 10: Evaluar resultados y documentar el proyecto

## Descripción

Finalmente se realizó una evaluación general del proyecto con el propósito de verificar el cumplimiento de los objetivos planteados. Además, se documentaron las actividades realizadas, los resultados obtenidos y las mejoras identificadas para futuras etapas.

## Resultados obtenidos

1. Se identificó la información más consultada por los pacientes.
2. Se recopiló y organizó información médica.
3. Se diseñó el modelo de base de datos.
4. Se implementó una base de datos en PostgreSQL.
5. Se definió la conexión entre la base de datos y la página web.
6. Se realizaron pruebas de funcionamiento.

## Conclusión

El proyecto permitió desarrollar una propuesta de solución para el Consultorio Santa María Josefa mediante una base de datos conectada a una página web. La información relacionada con horarios, especialidades médicas, contacto y ubicación podrá mantenerse actualizada y disponible para los pacientes, contribuyendo a una mejor gestión de la información del consultorio.
