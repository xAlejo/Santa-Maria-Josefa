# Actividad 1: Identificar la información más consultada por los pacientes

## Descripción

Se realizó una consulta para identificar la información que los pacientes del Consultorio Santa María Josefa solicitan con mayor frecuencia[cite: 1]. El objetivo fue determinar qué datos debían considerarse prioritarios para el desarrollo de la base de datos y la página web[cite: 1].

Durante esta actividad se identificó que la información más consultada corresponde a:

1. Horarios de atención.
2. Días disponibles.
3. Especialidades médicas.

## Resultado obtenido

Se determinó que la página web y la base de datos debían enfocarse principalmente en la publicación de horarios, días de atención y especialidades médicas, ya que son los datos más solicitados por los pacientes[cite: 1]. Esta información sirvió como base para el desarrollo de las actividades posteriores del proyecto[cite: 1].
